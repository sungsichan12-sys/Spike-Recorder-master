# 기존 측정·녹음 기능 검토

검토일: 2026-10-16

게임과 UI 추가 기능을 제외하고 기존 엔진의 파일 입출력, 샘플 버퍼, 필터, FFT, 마커 및 스파이크 분석을 검토했다. 재현된 오류를 수정했고, 실제 엔진 코드를 연결한 창 없는 회귀 검사 22개가 모두 통과했다. 합성 신호와 테스트 WAV를 사용했으며 실제 센서 측정 결과는 아니다.

## 확인 결과

| 기능 | 확인 범위와 결과 |
| --- | --- |
| WAV 입력 | 8/16/24비트 PCM, 32비트 실수 파일의 형식·길이·샘플 값 검사 통과 |
| 파일 재생 경로 | 파일 로드, 버퍼 프리로드, 위치 탐색 검사 통과. 스피커의 실제 소리 출력은 검사하지 않음 |
| 녹음 저장 | 기존 FileRecorder로 2채널 WAV 저장 후 다시 열어 샘플 값과 길이 일치 확인 |
| 녹음 메타데이터 | 채널 정보와 시간 배율 저장·복원 확인 |
| 이벤트 마커 | 시간 변환과 줄바꿈 없는 마지막 줄 처리 확인 |
| 파형 버퍼 | 원시 샘플, 최소·최대 포락선, 마지막 불완전 구간, 잘못된 간격 처리 확인 |
| 필터 | 임펄스 시작 시점, 블록 간 연속성, 고역통과 DC 제거, 50Hz 노치 감쇠, 정수 출력 포화 확인 |
| FFT | 알려진 주파수의 결과, 표시 캐시, 진폭 비례성, 낮은 샘플링률 범위 검사 통과 |
| 스파이크 분석 | 알려진 펄스 위치 검출, 발화 간격과 상관 집계 확인 |
| 트리거 평균 | 큰 진폭에서 평균값 유지, 홀수 길이 구간 처리 확인 |
| 마이크·USB/HID 실시간 수신 | 입력 경로는 코드로 검토. 실제 신호를 넣은 검사는 미실시 |
| 센서 보정·ECG 심박수·장치 제어 | 실제 장치가 없어 실측 검증하지 않음 |
| 펌웨어 업데이트 | 실행하지 않음. 검사 중 호환성 목록 다운로드 실패 메시지가 있었으며, 기존 로컬 목록을 사용하는 경로는 유지됨 |

## 수정한 오류

1. **8비트 WAV의 진폭이 절반으로 변환됨:** 16비트 범위로 변환하는 배율을 수정했다. 스파이크 검출에서도 같은 배율을 적용했다.
2. **실수 WAV의 NaN이 최대 진폭으로 표시됨:** 유한하지 않은 샘플을 0으로 처리하고 정상 샘플의 포화 처리는 유지했다.
3. **24비트 PCM 길이가 한 샘플 짧게 보고됨:** 포함된 디코더가 실제로 반환하는 마지막 샘플과 보고 길이가 다른 사례를 재현했다. 유효한 RIFF data 크기로 확인되는 한 프레임 이내의 차이만 보정한다.
4. **필터 출력이 두 샘플 밀림:** 내부 이력 두 칸을 결과에 복사하던 오류를 수정했다. 초기 계수·상태를 명시적으로 초기화하고 정수 변환 시 범위를 벗어난 값이 뒤집히지 않게 했다.
5. **트리거 평균의 16비트 누적 오버플로:** 넓은 정수로 합산한 뒤 평균을 계산한다. 홀수 길이 구간의 마지막 샘플도 읽는다.
6. **FFT 크기 값을 바이트 단위로 변경:** 실수 수치의 가중 평균으로 바꿨다. 수정 전 진폭 비율 검사 실패를 재현했으며, 수정 후 입력을 절반으로 줄이면 표시 크기도 절반이 된다. 낮은 샘플링률에서는 유효 범위 밖 주파수의 배열 접근도 막았다.
7. **포락선의 마지막 구간에서 출력 버퍼 범위를 초과할 가능성:** 필요한 구간 수를 올림으로 계산하고 마지막 구간의 실제 길이만 읽는다. 0 이하 간격과 가장 오래된 유효 샘플의 경계도 정리했다.

## 재검사 방법

프로젝트 폴더에서 실행한다. 앱 창이나 컴퓨터 유즈는 사용하지 않는다.

```powershell
.\build_windows.bat
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run_core_checks.ps1
```

결과: `RESULT 22 passed, 0 failed`

- 테스트 코드: `tests/core_regression.cpp`
- 최종 결과: `tests/core-artifacts/result.txt`
- 수정 전 재현 기록: `tests/core-artifacts/before-fixes.txt`
- 테스트 WAV·로그·설정은 `tests/core-artifacts`에 격리된다. 사용자 녹음과 설정을 시험 데이터로 덮어쓰지 않는다.
- 새 빌드는 기존 실행 BAT가 사용하는 실행 파일에 반영했다.

## 판단의 한계

현재 폴더에 Git 이력이 없으므로 처음 다운로드한 정확한 커밋과의 일대일 대조는 할 수 없다. 이번 결과는 현재 코드에서 기존 핵심 기능을 검사한 결과이며, 초기 버전과 모든 동작이 같다는 보증은 아니다. 센서 실수신과 실제 버튼·단축키 조작까지 모두 검증됐다고 판단해서는 안 된다.
