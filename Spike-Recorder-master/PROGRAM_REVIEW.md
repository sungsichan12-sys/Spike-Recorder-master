# 프로그램 검토 및 디노 그래픽 개선 — 2026-10-17

이번 검토는 실행·업데이트, 오디오/HID 입력, 파일 재생·녹음·분석, 파워 측정기, 게임 경로를 대상으로 했다. 화면을 조작하거나 실제 앱 창을 열지 않고 소스 검토, 헤드리스 검사, 장면 파일 렌더링으로 확인했다. 모든 하드웨어·모든 사용 상황의 무결함을 보장하는 결과는 아니다.

## 디노 그래픽

- 상자 중심 모델을 직접 만든 곡면/다각형 공룡으로 교체했다. 몸통·배·턱·눈·눈썹·발톱·등 돌기·분절 꼬리를 구성했다.
- 이동 거리와 점프 상태에 맞춰 다리 관절, 발, 몸통과 꼬리가 움직인다.
- 층이 있는 사암 협곡, 도로 가장자리, 바위와 식물, 아침 하늘·해의 빛 번짐·거리 안개·접지 그림자를 추가했다.
- 점수와 조작 설명 뒤에 어두운 페이드를 넣어 밝은 배경에서도 읽히도록 했다.
- 다각형별 OpenGL 호출을 하나의 삼각형 묶음으로 합쳤다. 디노 렌더링 소스는 최적화 옵션을 사용한다.
- 점프·긴 점프·충돌 수치는 변경하지 않았다. 이미지 파일이나 외부 모델 다운로드가 필요하지 않다.
- `tests/dino-ground.png`, `tests/dino-jump.png`는 실제 장면 코드가 출력한 면으로 만든 미리보기다. 앱 전체 화면 캡처가 아니며 UI 글씨·패널은 포함하지 않는다.
- 이 PC에서 120개 장면의 CPU 기하 계산은 평균 3.77ms/장면, 최대 가시 면 수는 2,194개였다. 최적화 전 약 11.17ms였다. OpenGL 표시·센서 처리까지 포함한 실제 FPS 측정은 아니다.

## 함께 수정한 문제

1. Player: 닫은 재생 스트림 핸들을 초기화하고 중복 종료, 생성 실패, 잘못된 길이·위치 조회를 안전하게 처리했다.
2. HID: 호출자가 제공한 프레임 용량까지만 읽고 남은 데이터는 다음 호출로 넘긴다. 40,000프레임 링에서 30,000프레임 출력 배열을 넘기는 상황을 방지했다. 링 인덱스는 atomic으로 변경했다.
3. HID 연결 해제 후에는 오디오 전환 뒤 이전 HID 처리 경로를 계속 실행하지 않는다. 시리얼 포트 소실 경로의 임시 배열도 해제한다.
4. 파일 교체·수동 탐색 시 bufferReset 알림을 보내 분석 캐시와 상대 세기 보정을 초기화한다. 연속 재생은 초기화하지 않는다.
5. 종료 시 게임 플러그인과 창을 엔진이 살아 있는 동안 정리한다. 분석 창의 중복 삭제를 제거하고 SDL 창·컨텍스트·포인터 초기화와 실패 처리를 보강했다.
6. Windows에서 매 프레임 창 크기를 재설정하던 동작을 제거하고 macOS 전용 크기 보정은 해당 플랫폼에서만 실행한다.
7. 업데이트를 적용한 후 임시 EXE를 소비해, 이후 직접 빌드한 원래 EXE가 오래된 임시 파일로 되돌아가는 상황을 방지했다. 실행 중 파일이 잠겼을 때는 업데이트를 보관한다.

## 확인 범위의 한계

- 실물 Human / Neuron SpikerBox가 연결되지 않아 실제 USB/시리얼 수신, 연결 중단·재연결, 센서별 채널/샘플링률과 보정은 검증하지 못했다. HID 검사는 합성 링 버퍼로 수행했다.
- 사용자의 다른 작업을 방해하지 않도록 앱 창을 열지 않았다. 실제 OpenGL 표시, 모니터 배율·창 크기 변경, 장시간 게임 플레이는 별도 확인이 필요하다.
- 펌웨어 호환 목록의 온라인 다운로드 실패 메시지는 테스트에서도 발생했다. 번들 파일을 사용하는 시작 경로는 동작했지만 온라인 업데이트 성공을 확인한 것은 아니다.
- 기존 코드의 미사용 변수·부호 비교·들여쓰기 컴파일 경고가 남아 있다. 이번 빌드는 오류 없이 완료되었다.
- 디스크 부족, 장시간 대용량 녹음, 녹음 도중 입력 포맷 변경 등은 이번 자동 검사 범위에 포함하지 않았다.
