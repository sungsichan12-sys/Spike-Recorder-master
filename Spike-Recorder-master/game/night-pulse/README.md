# Night Pulse 3D

`G` → **Night Pulse 3D**에서 실행합니다. 드럼 앞에 앉은 1인칭 화면입니다. 한 번 힘을 줘 신호가 기준선을 넘을 때 한 번 연주합니다. 다음 입력 전에는 힘을 뺍니다. 노트가 북·심벌 위 표시원에 닿는 순간 입력하면 됩니다. 악기는 노트에 맞게 자동으로 선택되므로 방향 조작은 필요 없습니다.

- 120 BPM, 56개 노트, 약 35초의 한 곡입니다. 시작 전 4박 카운트가 있습니다.
- Perfect ±80 ms / Great ±140 ms / Good ±200 ms. 지나간 노트와 박자 밖 입력은 실수로 처리합니다. 실수 12회면 종료합니다.
- Space·Enter 또는 왼쪽 클릭으로도 시험할 수 있습니다. 키를 누르고 있으면 자동 연주되지 않습니다.
- `[` / `]`로 플레이 중 감도를 바꾸고, `Esc` 또는 `Games [G]`로 목록에 돌아갑니다.
- 시작 전·결과 화면에서 `M`으로 반주를 켜거나 끕니다. 마이크·입력 없음 모드는 스피커 소리가 입력으로 재인식되는 것을 줄이기 위해 기본 무음입니다. 마이크와 반주를 함께 사용하려면 이어폰을 사용하고 M을 누릅니다.
- 결과가 표시된 후 신호·Space·클릭으로 재시작합니다.

## 그래픽

`Stage.h`가 가까이 배치한 드럼·심벌, 두 스틱, 타격 반응을 3D 면으로 생성합니다. 사람 캐릭터는 제거했습니다. `src/games/Scene3D.h`에서 원근 투영, 조명, 화면 경계 처리를 수행합니다. 드럼 통과 스틱은 곡면 음영을 사용하고, 테두리와 심벌에는 반사광이 적용됩니다. 가까운 악기가 먼 악기를 픽셀 단위로 가립니다. 이전 배경·인물 PNG는 새 렌더링에 사용하지 않습니다.

노트 판정과 무대 렌더링은 분리되어 있습니다. 입력하면 스틱이 악기에 닿고 튀어 오릅니다. 박자가 틀려도 타격 동작은 보이지만 점수는 판정에 따라 처리합니다. 창 크기나 렌더링 횟수가 점수·판정 시간을 바꾸지 않습니다.

`Motion.h`는 고정 길이 스틱의 준비 동작, 즉시 타격, 빠른 반동과 느린 복귀를 계산합니다. 양손 타격 기록을 따로 보관해 다음 입력이 반대 손의 반동을 끊지 않습니다. 북 가죽만 짧게 진동하고 통·테두리는 고정됩니다. 라이드는 받침대를 중심으로 흔들리며 다른 북을 쳐도 진동이 이어집니다. 빠른 반동에는 짧은 궤적, 타격에는 작은 카메라 반동과 퍼지는 표시원이 붙습니다. 정확한 타격일수록 반응이 조금 강하며 센서의 실제 힘을 측정하는 효과는 아닙니다. 결과 화면에서도 남은 동작은 자연스럽게 멈추고, 재시작하면 모두 초기화합니다.

`Stick.h`는 둥근 뒤끝부터 손잡이·어깨·가는 목·타원형 나무 팁까지 하나의 연속 곡면으로 그립니다. 은은한 세로 나뭇결과 반사광을 적용합니다. 반동 중에는 그립 위치를 고정하고 스틱을 회전시키며, 다음 악기로 이동할 때 그립과 각도를 함께 보간합니다.

드럼 통에는 베어링 가장자리와 위·아래 둥근 금속 테두리, 러그와 장력 볼트를 두었습니다. 심벌은 중앙 벨에서 얇은 끝선까지 굴곡이 이어지는 회전 곡면이며, 하이햇은 두 장의 금속판을 분리해 그립니다. 플로어 탐의 세 다리, 랙 탐 연결대, 킥 테두리와 포트, 스피커의 둥근 캐비닛과 콘도 입체 형태로 구성합니다. `src/games/ModelMesh.h`의 공통 형상을 사용합니다.

고밀도 모델은 드럼·심벌의 원주를 64각으로, 가죽 표면 격자를 6×64로, 스틱 원주와 길이 단면을 각각 두 배로 늘립니다. 금속 테두리와 심벌 프로파일은 추가 단면을 곡선으로 보간합니다. 스피커 캐비닛의 둥근 모서리도 세분화합니다. 공유 꼭짓점의 조명·변환을 재사용하고, 최종 삼각형 버퍼는 필요한 크기를 먼저 확보합니다. 동일한 카메라에서 세트의 가시 삼각형은 10,435→32,847개입니다.

## 음악과 모듈

기존 `assets/night_pulse.wav`를 BASS의 독립 스트림으로 재생합니다. 반주가 켜지면 재생 위치를 기준으로 노트 시간을 정합니다. 오디오 오류 시 상태를 표시하고 무음 시간으로 계속합니다. 게임 종료 시 게임 자신의 스트림만 해제합니다. 실제 출력·센서 장치의 지연 보정은 별도 수행하지 않았습니다.

반주를 켜면 입력에 맞춰 스네어·탐·라이드 타격음도 재생합니다. `generate_hits.py`로 합성한 짧은 WAV를 사용합니다. 기본 무음 모드에서는 타격음도 꺼져 있어 마이크로 소리가 다시 들어가지 않습니다.

게임 API v3는 기존 구조의 끝에 `draw_gradient_triangles`를 추가합니다. 꼭짓점별 색과 역깊이를 전달해 부드러운 음영과 픽셀 단위 가림을 구현합니다. API v4는 구조를 유지하면서 한 번에 65,536개 삼각형을 처리하도록 보장합니다. API v5는 종료 점수를 알리는 `report_result` 콜백을 추가합니다. 현재 호스트는 v1/v2/v3/v4 모듈도 받아들이며, 새 v5 모듈에는 갱신한 호스트가 필요합니다. 다른 게임은 `game/<이름>/` 아래 소스와 `game.ini`를 두는 기존 구조를 그대로 사용할 수 있습니다. Makefile이 게임 헤더 의존성도 추적합니다.

Night Pulse는 완주·탈락 시 한 번만 결과를 알립니다. 호스트가 아직 결과를 저장하지 못했다면 1초 간격으로 다시 시도합니다. 재시작하면 새 run ID를 사용하고, 녹화 파일 입력의 결과는 연습으로 제외합니다. 이름은 홈페이지에서 다음 판을 시작하기 전에 설정합니다. 자세한 실행 방법은 최상위 `SERVER_SETUP.md`를 참고합니다.

## 검증

- `tests/night_pulse_3d_tests.cpp`: 완주·판정 경계·탈락·연타·재시작·신호 입력·프레임 지연·렌더링 경계 검사. 오디오 장치를 열지 않습니다.
- `tests/night_pulse_smoke.cpp`: 실제 배포 DLL을 불러 완주·탈락·재시작·3D 그리기 콜백을 검사합니다. 무음으로 실행합니다.
- `tests/render_night_pulse.py`: 게임이 요청한 실제 그리기 명령을 PNG로 렌더링합니다. 컴퓨터 화면을 캡처하거나 앱 창을 열지 않습니다.

실제 앱 창에서의 플레이, 오디오 출력 지연 및 연결된 센서 검증은 수행하지 않았습니다.
